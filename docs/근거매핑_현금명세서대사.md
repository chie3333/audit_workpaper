# 근거 매핑 — 현금및현금성자산 명세서 계산검증·장부대사 (시범 절차)

원문은 저장하지 않고 위치와 요약만 기록한다. (기준서는 한국공인회계사회 저작물)
코드의 `content/sources.json` → `verified_locations`는 이 문서와 같아야 한다. 콘텐츠 검증은 여기 없는 위치를 '원문 인용·근거 요약'의 근거로 쓰면 거부한다.

## 서식 ↔ 기준서 대조 (원문 확인)
- 서식 '실증절차'!A7 = 감사기준서 330 문단 18 (중요한 계정잔액에 실증절차 설계·수행) — 문구 일치
- 서식 '실증절차'!A8 = 감사기준서 330 문단 20 (결산절차 관련 실증절차: 재무제표 정보와 회계기록 일치·조정) — 문구 일치
- 시범 절차 = 서식 A!A17~A19 (명세서 입수, 계산검증, 보조부 대조 / 명세서 스캔). 경영진 주장 서식 표기: C, V (A!J17)
- 총괄표 = 서식 A!A15~A16 (당기말 vs 총계정원장, 전기말 vs 전기감사보고서). 주장 E, C, CL (A!J15)
- 실사 = 서식 A!A20 (현금, 미사용수표 및 어음의 실사). 주장 E, C, RO (A!J20)
- 금융기관 조회 = 서식 A!A21 (금융기관 등에 대한 조회). 주장 E, RO (A!J21)
- 경영진 주장 코드·명칭 = 서식 A!A7:H10

## 미확인
- 서식이 참조하는 Audit Guide 3320 외부조회, 조서번호 2302 — 자료 없음
- 회계감사 실무지침 — 자료 없음
- 국내 추가·변경 문구(진한 기울임체) 표시는 PDF 텍스트 추출로 확인 불가 — 문단별로 부록 대조 필요
- 분류 검토 절차(`cash.classification_review`): 서식에서 이 절차의 위치와 주장 표기 미확인. 주장 CL은 사용자가 정함
- 분류 기준: 기업회계기준서 제1007호(현금성자산 정의)·제1001호(유동·비유동 구분) 문단 — 자료 없음. 안내는 '보완 설명·미확인'
